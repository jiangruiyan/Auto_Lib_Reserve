# 南开大学津南中心馆单人研读间自动预约系统

一个用于**南开大学津南中心馆单人研读间**的预约小工具。每天 22:00 系统开放次日预约时，程序会按预先配置的房间和时段，自动、准点地提交预约请求。

> ⚠️ **使用前请先阅读文末的[免责声明](#免责声明)。**

## 功能特点

- **图形化界面**：`gui.py` 提供完整的图形界面，登录、改配置、发起预约都在窗口里完成，无需命令行。
- **准点提交**：22:00:00 自动发送预约请求，并带有失败重试（每 0.5 秒一次，连续 10 次失败后停止），可容忍几秒内的本机时钟偏差。
- **密码不经过程序**：登录在真实的浏览器（Chrome 或 Edge）窗口中手动完成，程序只读取登录后产生的 token，**不会读取、保存你的账号和密码**。
- **预约今天或明天**：在界面里选择。选明天会等到 22:00 再发送，选今天则立即发送。
- **提前自检**：发送前会检查 token 是否过期、网络是否可达、房间是否存在，并给出中文提示。
- **提供EXE安装包**：Releases 里提供Windows系统的 exe 安装包，下载后双击即可安装，适用于不太会电脑的小白。技术人员也可直接 clone 源码并在本地安装依赖，直接运行 Python 程序。

## 工作原理

图书馆预约网站是前后端分离的单页应用，页面数据都来自 JSON 接口，因此无需解析网页，直接调用接口即可。整体流程如下：

```
gui.py（图形界面入口，内部调用下面两步）
  ├─ 登录（get_token.py 的 fetch_token）
  │    └─ 启动 Chrome / Edge → 你在统一身份认证页手动登录
  │    └─ 登录后页面会向图书馆系统换取登录凭证（token，JWT，有效期 2 小时）
  │    └─ 程序监听该响应，把 token 保存到 token.txt
  └─ 预约（book.py 的 book_room）
       └─ 读取 token.txt 和 config.json
       └─ 预检（验证 token 与房间）
       └─ 等到 22:00:00，提交预约请求；失败则按间隔重试
```

预约请求只需要携带 `Authorization` 请求头，没有额外的签名或时间戳参数。

## 快速开始

### 前提条件

- Windows 系统（针对 EXE 程序）
- 已连接**校园网**
- 已安装 **Google Chrome 或 Microsoft Edge**（登录时使用）
- 从源码运行需要 Python 3.10+

### 方式一：使用打包好的 exe（适合小白）

1. 到 Releases 页面下载安装包 `NKU_Auto_Lib_Reserve_v2.0.exe`，双击并按照提示进行安装，建议创建桌面快捷方式。
2. 双击桌面快捷方式或者 `LibReserve.exe`，打开图形界面。
3. 每天 **21:50 左右**：
   1. 点击「登录（Chrome）」或「登录（Edge）」，在弹出的浏览器里手动登录，成功后界面会显示 token 状态。
   2. 在「② 配置」里核对/修改房间号、开始和结束时间，点「确定」保存。
   3. 在「③ 预约」里选择「明天（今晚 22:00 准时预约）」，点「开始预约」。
   4. 保持窗口开启、电脑不休眠，程序会在 22:00:00 自动发送请求。
4. 看到日志里的“预定成功”即可。

> token 有效期只有 **2 小时**，必须当天获取。预约今天的时段则选择「今天（立即预约）」。

### 方式二：从源码运行

```bash
git clone https://github.com/jiangruiyan/Auto_Lib_Reserve.git
cd https://github.com/jiangruiyan/Auto_Lib_Reserve.git

pip install -r requirements.txt

# 直接运行图形界面
python gui.py
```

命令行方式仍然保留：`python get_token.py`（获取 token）、`python book.py`（预约）。

## 配置说明

> 图形界面里也可以在「② 配置」中直接修改这些字段，手动编辑 `config.json` 同样有效。

`config.json`示例：

```json
{
  "room_name": "津南中心馆301",
  "room_id": "1977990826026962944",
  "use_type": "1976112199572230144",
  "begin": "09:00",
  "end": "23:00"
}
```

| 字段 | 说明 |
|---|---|
| `room_name` | 房间名称备注，仅方便自己识别，程序不读取 |
| `room_id` | 房间 ID，**必须保留引号**（字符串格式），查看`room_id`的方法在下面 |
| `use_type` | 用途 ID，好像 `1976112199572230144` 是通用的，一般不用改 |
| `begin` / `end` | 预约的起止时间，格式 `HH:MM`，开始必须早于结束 |

### 如何找到自己的 `room_id` ？

1. 用浏览器（Chrome 或 Edge）登录[预约网站](https://libroom.nankai.edu.cn/)，按 `F12` 打开开发者工具，切换到 **Network（网络）** 面板，筛选 **Fetch/XHR**。
2. 进入一个具体房间的预约界面（如津南中心馆301）。
3. 点开名为 `getRoomDtoByRoomIdAndDate` 的请求，在 **Payload（载荷）** 中即可看到 `roomId`。

> 抓包时请注意：Cookie、`Authorization`、token 都是你的登录凭证，截图分享前务必抹掉。



## 常见问题

**Q：提示 token 已过期？**
token 理论上只有 2 小时有效期，保险起见请在 21:30 之后重新运行“获取token”。

**Q：提示无法启动浏览器（Chrome/Edge）？**
请确认已安装 Google Chrome 或 Microsoft Edge 浏览器。

**Q：提示无法连接图书馆系统？**
请确认电脑已连接校园网。

**Q：22:00 到了却提示未开放？**
可能本机时钟偏快几秒，程序会自动重试。建议在 Windows 的“日期和时间”设置中点击“立即同步”。程序默认设置的重试间隔是0.5 s，重试次数不超过10次，也就是说本机时钟偏快5 s以内的误差都能够容忍。

**Q：预约失败，提示时段冲突或已被预约？**
房间在该时段已被他人抢先预约，或你的时间区间与房间开放时段不符，请调整 `begin` / `end`。

**Q：某次请求显示网络异常，但网站上已经有预约？**
请求可能已被服务器处理但响应超时，请到网站确认，不要重复预约。
